看梁文锋 4 小时发言有感

发表于2026-08-03|更新于2026-08-03
|总字数:1.8k|阅读时长:5分钟|浏览量:

今天看完了梁文锋在投资者交流会上的发言，全文三万多字，看下来觉得时间花的值（虽然也是在等 agent 干活的时候看的）。

叠甲：鉴于这是投资者大会上的发言，且本人的感悟也只是读了这篇发言（且懒得二次验证），所以其中不一定都是真相，甚至极大概率梁文锋在里面讲了不少故事。但其中蕴含的一点精华就足以对你我有益，故此有此文。

克制

首先是他非常强调克制。本身幻方和大企业比规模不能算大，所以他们能这么成功，离不开他们始终坚持走在实现自己愿景的路上，以及坚定地执行路线图。他们专注于智能的提升，他们认为多模态并不是智能提高的表现，所以没有当成主线去做，更多是为了回应 C 端的期待。同样，他们认为世界模型也没有提高模型智能，所以也没有做这个。在他们的路线中，智能是第一重要的，等模型能够自主学习和进化之后，他们的任务才算阶段性完成，届时才会开始具身智能这些其他方向的研究。关于具身智能，他认为是一定要做的，因为只有这样 AI 才能更好落地，普惠更多人，做更多事。但是他们是一条线的在去做，而不是像其他公司多线并行。

关于克制另一个很好的体现是商业化。众所周知的是，国内御三家都在积极谋求上市。不难理解，毕竟大模型是一个需要砸钱的产业。但在梁文锋这次的发言中，我们听到了商业化凡尔赛的版本。他说并没有刻意的去追求商业化，就和没有想去维护 C 端用户一样（经典发言： C 端用户赶都赶不走），只是就像求其上者得其中一样，当你锚定的是一个更高的目标——智能时，商业化就是一个水到渠成的事情。当然不是说商业化不重要，否则也就没有这次谈话了，只是并不以商业化为目的，这也是克制的一种表现。

体现克制的另外一点是，对于金钱的清醒。先别急着说和上一段重复了，只是开头这一句形似而已。众所又周知， deepseek 是开源的，甚至他们很乐意帮有能力的公司部署 deepseek 。其中一个原因是，有更多公司一起研究，能加速智能这一目标的实现，另一个原因是，梁文锋觉得这里面的利润很大，他们一家公司不可能吃下，他们已获得的已经够了（这也体现在他们的 api 定价上）。横向上，他们不参与到具身智能和世界模型的竞争，是对这部分利润保持了克制，甚至局限点的横向上， glm 和 kimi ，梁文锋对其的态度也是友好的，可以合作的。纵向上，他们只做模型这一层，不参与服务器和算力的竞争，但会帮助华为做算子适配（这点真是伟大，虽然不排除有国外的卡受限很大的原因）。高度专注，非常清醒和克制。很多初创会一上来就想吃掉整个市场，尤其如果那家初创如果还出现过 deepseek 时刻这样的奇迹的时候，更是会想要垄断。但梁文锋的克制让 deepseek 没有走向这条道路，这很难得，也让 deepseek 得以有今天这样健康的状态。

但我们也需要看到， deepseek 创造了一个斩杀线，尤其是最近 dsv4f 出来后，没它强又比它贵的公司无异于被宣判的了死刑。所以就算他肯让利，也得有能力上桌才行。

数据 人工 智能

这一章严格来讲，并不算发言的重点，是我将发言的一部分和之前看过的一系列内容有关关联到了一起。首先，梁文锋强调数据很重要。他们团队，有一半的人在负责算法，另一半的人就是在洗数据。没错，就是以前科研民工干的事（真是感慨，以前科研入门生怕被拉去洗数据，现在洗数据的机会都不一定有）。大模型领域有一句名言，和一句谚语。名言是：rubbish in, rubbish out。谚语是：有多少人工就有多少智能。今年年初，我看到一个团队用高质量数据，以极小的参数，做出了一个媲美当时 GPT 前一个小版本的模型。这无疑是震撼的，但大家都应该因此去洗数据吗，答案是否定的。一个是，如何洗出高质量数据，是有挑战的，要多少时间，是不确定的。那个团队拼尽全力，也没干过当时的 GPT ，后面更是杳无音信。梁文锋也说，当前别说国内，就连国外都还远远没到 scaling law 的边界，也即堆参数的效果依然会十分明显。一边充满了不确定，另一边收益明显，大家都知道应该怎么选。现阶段，洗数据还是只能作为一个辅助或者支线，还没到能成为主线的程度。可能后续到大家触及到 scaling law 边界之后，我们会看到一个洗数据的黄金时代吧。

谈及这个，我脑子里总会出现一个画面，人类用尽全力（所有数据）托举起另一个物种，嘴里还说着，收下吧，这是人类最后的荣光 doge 。

正事只占一半的时间

这既是他们克制带来的好处，也是他们能够不断有创新的关键。梁文锋说他们员工公司上的事只占工作的一半时间（还是在六点准时下班的情况下），剩下一半时间允许员工去研究自己的东西，他认为这是有意义的，因为研究需要保持一个好的状态。我觉得这还是挺有启发的一件事。你可以说大厂员工经常加班是因为大部分员工并不从事这种研究型的工作，但是哪怕开发也是脑力劳动，且大厂研究基模的部门比开发部门还要辛苦。虽然这部分只占梁文锋发言的极小一部分内容，但我很想要其他公司学习，也很羡慕。而且对于大部分疲于内卷的哈工深学子来说，我相信也是有一定启发意义。

总而言之，梁文锋是非常独特的企业家，也是一个成熟的理想主义者。希望 deepseek 越做越强。
