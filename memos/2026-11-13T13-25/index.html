kmeans 算法相信了解过机器学习的读者都知道，它居然被研究出了一个全方位更优的升级版本，叫 emeans ： e-means: outperforming k-means in one-tenth the epochs 。我大受震撼，这种古早的算法居然被人研究出了如此高效的一个版本， kmeans 在很多地方都是某种拿来即用的砖，快成为机器学习基建的一部分了，不敢想影响有多大（虽然也可能毫无波澜）。这个时代也不是没有很创新的成果，但是这种离我如此之近以至于能让我都知道具体有多厉害的成果，也是非常少见了。震撼。

这周比完赛之后还推进了一下 HITA 那边的事务，大家都好忙，人手上捉襟见肘。只有我这个闲人忙完手上为数不多的活之后，能比较及时且有空的推进。我们 HITA 也是人才济济啊，坐等其他开发者飞黄腾达拉我一把（幻想中）。最近突然有个想法，想了解一下手机端的 agent 是怎么工作的，我们 HITA 也要做到 agent 友好才行，面向的用户应该也包括 agent 。但是 agent 友好化改造的形式和方法还没想好，等我了解一下再看看，在这先预告一下。

说起来，揭榜挂帅今年今年国一及以上的队伍少了一半，加上国三不加分且大三很多比赛来不及加分了，我预感这一届保研加分会是比较通货紧缩的一届。诚然大三也还有能加分的比赛，我也有参与一部分，但是加分的名额并不多，且竞争很激烈，肯定是不如往年的。

今晚还有个考察课的期末，本来平时分占 60 分，考试只占 40 ，试卷看着也不是没有送分题，复习应该简简单单应付就能不挂的才对，但是看学生自己的课程群里大家怎么都这么焦虑，感觉没有必要且传播不好的情绪。可能是人之常情吧，不喜（对事不对人，人都是不错的）。
